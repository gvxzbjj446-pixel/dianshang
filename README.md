# 家电直播工具箱

给微波炉、烤箱这类厨电直播团队用的单页小工具，打开 `index.html` 就能用，不用安装、不用登录。

按一场直播的流程分六块：

| 阶段 | 工具 | 做什么 |
|---|---|---|
| 播前 | 算到手价 | 日常价 → 直播间立减 → 满减 → 国补，一层层算出到手价，生成一句能直接念的报价 |
| 播前 | 写话术 | 填产品和卖点，按「留人 → 痛点 → 卖点 → 报价 → 促单 → 售后」生成讲款话术，每段可换说法，自动查违禁词 |
| 播前 | 查违禁词 | 标出广告法极限词、「零辐射」「营养不流失」「0 油」这类厨电常见的功效宣称、站外引流等风险词，给出改法，可以自己加词 |
| 播中 | 场控计时 | 按排品表倒计时，最后一分钟变黄、超时变红；要现场做菜的环节提前提醒预热、备菜；定时提醒喝水，开着时屏幕不熄灭 |
| 播中 | 数字人 | 卡通数字人主播：用浏览器语音念「写话术」里的话术，口型和字幕同步；能回答弹幕里问价格、国补、链接、售后等问题，也能自己加常见问题；有禁用词的句子会跳过不念 |
| 播后 | 下播复盘 | 算转化率、UV 价值、GPM、客单价、投放 ROI、退款率，生成能直接发群的复盘小结 |

说明：

- 填的内容只保存在当前设备的浏览器里（localStorage），不会上传到任何地方。
- 国补比例、上限和违禁词库只作参考，以平台和当地最新规则为准。
- 数字人是演示版：形象是画出来的卡通人物，声音用浏览器自带的中文语音（没有中文语音时只出字幕）。放进真实直播间前，请按平台对数字人直播的最新规则操作。
